# V0.6 — December 14, 2022 case-data package

This phase turns the approved historical case into a reproducible raw-data package for the 2027 Endymion exercise.

## Source window

The acquisition window is **20:30–22:45 UTC on December 14, 2022** (2:30–4:45 PM CST). The live exercise itself is mapped to **2:45–4:30 PM CST on February 6, 2027**.

The extra 15-minute buffer on each side makes preprocessing/looping easier and avoids clipping the first/last operational frames.

## One-command acquisition

Install data dependencies:

```bash
pip install -r scripts/requirements-data.txt
```

First validate that public AWS objects exist without downloading:

```bash
python scripts/prepare_endymion_case.py --list-only
```

Then acquire the package:

```bash
python scripts/prepare_endymion_case.py
```

This retrieves:

- KLIX NEXRAD Level II
- GOES-16 ABI L2 Cloud/Moisture Imagery for channels 2 and 13
- GOES-16 GLM L2 lightning files
- GOES-16 ABI L1b channels 2, 5, 13, and 15 for LightningCast reproduction
- MRMS MESH
- MRMS 0–2 km merged azimuthal shear
- MRMS precipitation rate
- MRMS merged reflectivity at lowest altitude
- Louisiana ASOS/METAR observations from selected stations

## Raw-data inventory

After downloading:

```bash
python scripts/validate_case_inventory.py --strict
```

To save a machine-readable inventory:

```bash
python scripts/validate_case_inventory.py \
  --strict \
  --json data/case_inventory.json
```

## Public-source findings

### NEXRAD

The existing downloader uses the public Unidata/NOAA Level II archive. The primary radar is **KLIX**.

### GOES-16 ABI and GLM

NOAA's GOES Open Data bucket contains public historical ABI L1b/L2 and GLM L2 products. V0.6 uses:

- `ABI-L2-CMIPC` channels 2 and 13 for participant satellite imagery
- `GLM-L2-LCFA` for observed lightning
- `ABI-L1b-RadC` channels 2, 5, 13, and 15 as historical LightningCast inputs

Official data registry:
https://registry.opendata.aws/noaa-goes/

### MRMS

NOAA's public MRMS AWS archive uses the layout:

```text
s3://noaa-mrms-pds/CONUS/<PRODUCT>/YYYYMMDD/
```

The first exercise package targets:

- `MESH_00.50`
- `MergedAzShear_0-2kmAGL_00.50`
- `PrecipRate_00.00`
- `MergedReflectivityAtLowestAltitude_00.50`

Official registry:
https://registry.opendata.aws/noaa-mrms-pds/

### Surface observations

The Iowa Environmental Mesonet maintains a scriptable historical ASOS/METAR archive. The starter station set is:

- MSY
- NEW
- BTR
- ASD
- HDC

The station list can be adjusted after the first acquisition test.

### Environmental analysis

SPC states that its hourly mesoanalysis archive is maintained from **2005 to present**. We should use the archive for participant-friendly hourly snapshots such as MLCAPE, effective bulk shear, and 0–1 km SRH rather than reconstructing those fields unnecessarily for V1.

SPC archive:
https://www.spc.noaa.gov/exper/mesoanalysis/

## What this phase does not yet do

Raw data acquisition is separate from rendering into participant-ready frames. After V0.6 acquisition is validated, the next pipeline step is:

1. Render GOES visible/IR.
2. Grid/render GLM as FED or another operationally familiar lightning display.
3. Render MRMS fields over the LIX/Endymion domain.
4. Reproduce LightningCast from archived ABI inputs.
5. Stage SPC environmental imagery.
6. Run `build_meso_cache.py --simulation-date 2027-02-06`.
7. Build the radar cache with the same exercise-date remapping.
