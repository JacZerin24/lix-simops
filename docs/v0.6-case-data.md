# V0.6 — May 12, 2021 case-data package

This phase turns the approved historical case into a reproducible raw-data
package for the 2027 Endymion exercise.

## Source window

The acquisition window is **06:00–07:45 UTC on May 12, 2021**
(**1:00–2:45 AM CDT**). The live exercise maps that 105-minute evolution to
**2:45–4:30 PM CST on February 6, 2027** using a facilitator-only
+13 hour 45 minute local-time shift.

## One-command acquisition

```bash
pip install -r scripts/requirements-data.txt
python scripts/prepare_endymion_case.py --list-only
python scripts/prepare_endymion_case.py
python scripts/validate_case_inventory.py --strict
```

The package contains:

- KLIX NEXRAD Level II
- GOES-16 ABI L2 Channel 13 infrared imagery for participant display
- GOES-16 GLM L2 lightning files
- GOES-16 ABI L1b channels 2, 5, 13, and 15 for LightningCast reproduction
- MRMS MESH
- MRMS 0–2 km merged azimuthal shear
- MRMS precipitation rate
- MRMS merged reflectivity at lowest altitude
- RAP analyses for 05Z, 06Z, and 07Z
- Louisiana ASOS/METAR observations from MSY, NEW, BTR, ASD, and HDC

Channel 2 is retained as a LightningCast input but is **not** presented as
participant-facing visible satellite imagery because the historical case is
overnight.

## Public sources

- NEXRAD Level II: NOAA/Unidata public archive
- GOES-16 ABI/GLM: NOAA Open Data on AWS
- MRMS: NOAA Open Data on AWS
- RAP: NOAA Open Data on AWS
- ASOS/METAR: Iowa Environmental Mesonet
