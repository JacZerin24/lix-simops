# V0.7 — Rendered Endymion case package

V0.7 turns the raw **May 12, 2021** source-case files into participant-facing
products replayed on the February 6, 2027 Endymion simulation clock.

## Environmental analysis

The environment tab uses official NOAA RAP analyses:

- RAP 90-mb mixed-layer CAPE
- RAP 0–6 km bulk shear
- RAP 0–1 km storm-relative helicity

The source analyses are 05Z, 06Z, and 07Z. They are explicitly labeled as RAP
products in the participant interface.

## Render locally reproducible products

```bash
python scripts/build_endymion_meso_inputs.py
```

This produces:

- GOES-16 infrared
- five-minute GLM flash-density images
- MRMS MESH
- MRMS 0–2 km azimuthal shear
- MRMS precipitation rate
- MRMS lowest-altitude reflectivity
- RAP MLCAPE
- RAP 0–6 km bulk shear
- RAP 0–1 km SRH
- surface observation maps

The final cache builder applies the +825 minute local-time shift and maps the
result to February 6, 2027.

## LightningCast

LightningCast remains the one product requiring the external CSPP Geo
processor. The repository downloads and validates ABI L1b
C02/C05/C13/C15, stages timestamped CSPP imagery, and incorporates those
frames into the normal time-remapped manifest.

```bash
python scripts/validate_lightningcast_inputs.py
python scripts/stage_lightningcast.py --input /path/to/cspp/output
python scripts/build_endymion_case.py --require-lightningcast
```

## Case-blindness protection

The participant cache validator checks that:

- participant timestamps are mapped to February 6, 2027
- participant asset filenames do not contain the historical source date
  `20210512`
- required radar/meso products contain sufficient frames
- every referenced asset exists
- participant manifests do not expose historical `source_key` values
