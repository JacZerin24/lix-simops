# Data sources

Planned data families:

- NEXRAD Level II / derived radar products
- GOES ABI
- GOES GLM
- LightningCast
- MRMS
- Surface observations
- Environmental analysis / guidance

## Repository policy

This repository stores code, configuration, manifests, and lightweight metadata only. Bulk meteorological archives must not be committed.

The data acquisition layer should eventually support downloading and preprocessing a selected historical case into a local scenario cache before an exercise begins.
