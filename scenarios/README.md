# Scenario packs

Each exercise should live in its own directory and define:

- `scenario.yaml` — master scenario metadata and simulation timing
- `event.yaml` — venue/event/partner information
- `injects.yaml` — timed and facilitator-released injects
- `resources.yaml` — enabled datasets and resource links
- `README.md` — facilitator notes and scenario-specific setup

Bulk archived weather data belong outside git.
